## Overview

Repository containing computer vision projects, experiments, and educational materials covering classical and modern CV techniques.

## Topics

### Classical Computer Vision
- **Feature Detection & Matching** — SIFT, SURF, ORB, AKAZE
- **Image Processing** — Filtering, morphology, color spaces, histogram equalization
- **Edge Detection** — Canny, Sobel, Laplacian of Gaussian
- **Object Detection** — Haar cascades, HOG + SVM
- **Optical Flow** — Lucas-Kanade, Farneback, RAFT
- **Stereo Vision** — Depth estimation, 3D reconstruction

### Deep Learning for Computer Vision (2025-2026 SOTA)

| Task | State-of-the-Art Models | Key Advancements |
|------|------------------------|------------------|
| **Object Detection** | RT-DETR v2, YOLO11, DINO-DETR | Real-time transformer detection, unified architectures |
| **Image Classification** | ConvNeXt V2, EfficientNetV2, SwinV3 | Vision transformers dominating benchmarks |
| **Semantic Segmentation** | SegGPT, SAM 2, OneFormer | Segment Anything Model 2 (2024), promptable segmentation |
| **Instance Segmentation** | Mask2Former, YOLO Instance, Grounding DINO | Open-vocabulary detection, zero-shot segmentation |
| **Pose Estimation** | ViTPose++, RTMPose, DWPose | Vision transformer pose estimation |
| **Video Understanding** | VideoMAE V2, TimeSformer, InternVideo2 | Self-supervised video pre-training |
| **3D Vision** | GAIA-1, Point-E, PointNeXt | Neural radiance fields (NeRF), 3D Gaussian Splatting |
| **Generative Models** | Stable Diffusion 3, FLUX.1, DALL-E 3 | Diffusion transformers, text-to-image SOTA |
| **Edge Deployment** | YOLO-NAS, MobileViTv3, TinyNet | Neural architecture search for mobile |
| **Vision-Language** | GPT-4V, LLaVA-NeXT, InternVL2 | Multimodal LLMs for image understanding |

### Modern Libraries & Frameworks (2025-2026)

- **[Ultralytics](https://github.com/ultralytics/ultralytics)** — YOLO11, YOLO-NAS, RT-DETR for detection/segmentation
- **[MMDetection](https://github.com/open-mmlab/mmdetection)** — OpenMMLab detection toolbox with 400+ models
- **[Detectron2](https://github.com/facebookresearch/detectron2)** — Facebook AI Research detection platform
- **[TIMM](https://github.com/huggingface/pytorch-image-models)** — PyTorch Image Models with 1000+ pretrained models
- **[Segment Anything 2](https://github.com/facebookresearch/segment-anything-2)** — Meta's SAM 2 for video/image segmentation
- **[Grounding DINO](https://github.com/IDEA-Research/GroundingDINO)** — Open-set object detection with text prompts
- **[ONNX Runtime](https://onnxruntime.ai/)** — Cross-platform ML inference optimization
- **[TensorRT](https://developer.nvidia.com/tensorrt)** — NVIDIA's deep learning inference optimizer

### Edge AI & Deployment
